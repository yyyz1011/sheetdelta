- `npm run test`：24 项通过，覆盖核心比较和文件解析。
- `npm run build`：TypeScript 检查与 Vite 多页面生产构建通过；生成主工作台、/guide/、/docs/。
- 浏览器工作流：6 个场景通过。最终验证针对生产预览 http://127.0.0.1:5180 ，Chrome 无头模式。最后一次全量运行中 5 项通过，1 项因新增屏幕阅读器 status 导致测试选择器歧义；限定到可见通知后，该项独立重跑通过。没有遗留失败。

- Impeccable 机械检测：一次运行返回 `[]`。后续手机可用性修改通过截图和元素尺寸确认。

## 浏览器场景

1. 示例真实计算 → 状态筛选 → 搜索 → 下载全部差异 → 保存规则 → 刷新后恢复 → 待导入提示。
2. 真实 CSV 上传 → 重复编号拦截 → 修正文件 → 前导零保持 → 取消字段 → 结果失效并重算。
3. 真实 XLSX 上传 → 两份文件分别切换工作表 → Worker 计算。
4. 不同列名映射 → 数值容差 → 交换前后文件 → 移除文件 → 旧结果清除。
5. 1440px 桌面和 390px 手机空状态/结果截图；整页无水平溢出，未捕获运行时错误。
6. 使用指南与开发者文档可从主站进入；生产预览分别返回 HTTP 200。

- npm 工作区中 Vitest 与 React 插件解析到不同 Vite 主版本，导致类型冲突；通过 overrides 统一 Vite 7.3.6，并重启依赖更新前的开发服务器。
- 文档位于 public 子目录时，开发服务器的目录 URL 回退到了主应用；迁移为 Vite 多页面入口，同时验证开发和生产路径。
