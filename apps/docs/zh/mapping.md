# 键与字段映射

键用于识别两侧的同一条记录，比较字段决定哪些值的变化需要关注。

## 选择稳定的唯一键

使用 SKU、订单号或其他在每份输入中唯一的编号。行号通常不适合作为键，因为行的位置可能改变。匹配基于标准化后的精确值，不支持模糊匹配。

## 映射不同列名

每组映射的 `left` 是原始数据的列名，`right` 是更新数据的列名，两侧名称可以不同。

## 使用复合键

订单有多个明细项时，可以同时使用订单号和明细号：

```ts
const options = {
  keys: [
    { left: 'orderId', right: 'order_id' },
    { left: 'lineId', right: 'line_id' },
  ],
  columns: [{ left: 'unitPrice', right: 'price' }],
};
```

复合键按元组编码，避免简单拼接分隔符造成碰撞。每个键字段都必须存在且非空，完整的键组合必须在每一侧保持唯一。

## 保留文本编号

把 `'001'` 这类编号保留为字符串。`'001'` 与 `'1'` 不相同。如果文件解析阶段已经将它转为数字 `1`，比较时无法恢复前导零。

## 选择比较字段

至少提供一个比较字段映射。未选中的字段不影响记录状态。同一侧的列在键分组或比较分组内只能映射一次；如有需要，键字段也可以出现在比较分组中。
