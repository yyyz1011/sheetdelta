# 比较规则

默认按标准化后的文本比较。数值容差需要针对每个比较字段单独开启。

## 默认值处理

| 值 | 默认比较结果 |
| --- | --- |
| `null`、`undefined`、`''` | 相同 |
| `10`、`'10'` | 相同 |
| `'10.0'`、`'10'` | 不同 |
| `'001'`、`'1'` | 不同 |
| `'A'`、`'a'` | 不同 |
| `' A '`、`'A'` | 不同 |

单元格值可以是字符串、数字、布尔值、null 或 undefined，不支持对象和数组作为单元格值。

## 文本标准化

`trim: true` 去除首尾空白。`ignoreCase: true` 使用 `en-US` 规则转为小写。这两个选项同时作用于键和比较字段，默认都是 `false`。

::: warning 标准化可能产生重复键
开启 `ignoreCase: true` 后，`'A'` 和 `'a'` 会成为相同的键。此时会返回校验错误，不会静默选择其中一行。
:::

## 数值容差

```ts
const options = {
  keys: [{ left: 'sku', right: 'sku' }],
  columns: [{ left: 'price', right: 'price', numericTolerance: 0.01 }],
  trim: true,
  ignoreCase: false,
};
```

`numericTolerance` 必须是非负有限数。数值的绝对差在容差以内时视为相同。只有有限的纯数值文本参与；货币符号、带千分位的数字和其他文本仍按文本比较。容差不影响键匹配。

## 精度

计算使用 JavaScript 的 IEEE 754 数字，而非十进制运算。精确金额比较建议先转换成统一格式的文本，或以分等最小货币单位表示为整数。
