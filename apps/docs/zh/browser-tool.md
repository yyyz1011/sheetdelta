# 浏览器工具

不需要编写代码，也能比较两份文件。当前工具界面为中文。

<a class="doc-path" href="/playground/" target="_blank" rel="noopener"><strong>打开表格对比工具 ↗</strong><span>文件在当前浏览器中处理。</span></a>

## 比较两份文件

1. 在**原始表格**中选择旧文件，在**更新后的表格**中选择新文件，也可以先点击**试用商品示例**。
2. Excel 工作簿包含多个工作表时，分别选择需要比较的工作表。
3. 为两侧选择编号列，在**比较字段**中映射并勾选需要关注的列。
4. 点击**开始比较**，筛选新增、删除和修改，查看单元格的变化前后值。
5. 点击**导出差异 CSV** 下载报告。

## 保存重复使用的规则

点击**保存规则**，保存字段映射和比较选项。在**我的规则**中，可以将规则应用到下一次导入的文件。当前浏览器最多保存 20 条规则，文件内容不会被保存。

## 支持的文件和限制

| 项目 | 限制 |
| --- | --- |
| 文件格式 | CSV、TSV、XLSX、XLS |
| 文件大小 | 每个文件 10 MB |
| 工作簿数据量 | 总计 50,000 行 |
| 列数 | 每张工作表 100 列 |
| 文件编码 | UTF-8，CSV/TSV 支持 GB18030 回退 |

首个非空记录被视为表头，重复列名和空列名会被拒绝。完全空白的行会跳过。CSV 引号字段可以跨物理行，一条记录不一定等于一行文本。

## 隐私与工作簿行为

文件在本地 Web Worker 中解析和比较，不上传、不持久化。保存的规则只包含名称、映射和选项。目前没有接入第三方广告或远程统计。

Excel 按显示值比较，不重新计算公式，不比较样式、批注或合并单元格语义。如有需要，先在 Excel 中重新计算并保存。当前数据限制不等于对恶意工作簿解压资源消耗的完整防护。
