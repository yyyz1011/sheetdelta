表里 SheetDelta
表格对比使用指南

把比较能力，接入你的项目。

网站使用的同一套 TypeScript 核心。无需 DOM、无需服务器，输入两组记录，获得可用于业务逻辑的差异结果。

npm 包名：sheetdelta-core。开源代码与问题反馈：GitHub。

安装 npm 包

npm install sheetdelta-core

本地开发

在 SheetDelta 项目根目录执行：

npm install
npm run pack:core

# 在另一个项目中，使用上一步生成的实际路径：
npm install /path/to/sheetdelta/artifacts/sheetdelta-core-0.1.0.tgz

比较两份商品数据

import { compareTables, exportDiffCsv } from 'sheetdelta-core';

const before = [
  { sku: '001', price: '129.00', stock: '240' },
  { sku: '002', price: '299.00', stock: '86' },
];
const after = [
  { id: '002', price: '299.00', stock: '72' },
  { id: '001', price: '119.00', stock: '240' },
];

const result = compareTables(before, after, {
  keys: [{ left: 'sku', right: 'id' }],
  columns: [
    { left: 'price', right: 'price' },
    { left: 'stock', right: 'stock' },
  ],
  trim: true,
  ignoreCase: false,
});

console.log(result.summary.changed); // 2
const csv = exportDiffCsv(result); // UTF-8 BOM + escaped CSV

配置说明

配置含义
keys至少一个键映射。支持多个字段组成复合键，编号必须非空且唯一。
columns至少一个比较字段映射。未选字段不会影响变化判断。
numericTolerance放在具体字段映射内。非负有限数，仅纯数值文本参与数值比较；其他内容仍按文本比较。
trim是否忽略首尾空格，默认 false。同时作用于键和字段。
ignoreCase是否忽略大小写，默认 false。同时作用于键和字段。

处理重复编号与缺少字段

import { compareTables, TableValidationError } from 'sheetdelta-core';

try {
  const result = compareTables(before, after, options);
} catch (error) {
  if (error instanceof TableValidationError) {
    // code: duplicate-key | missing-key | missing-column
    // side: left | right
    // rows: 从 1 开始的数据行序号，不含表头
    console.log(error.issues);
  } else {
    throw error;
  }
}

返回结果

rows 中每条记录含 key、status、before、after、changes。状态为 added、removed、changed、unchanged。匹配记录和删除记录沿用原表顺序，新增记录随后按新表顺序追加。leftIndex / rightIndex 为从 0 开始的输入记录位置。

summary 包含四种状态的数量、结果总记录数 total、原始记录数 before 和更新后记录数 after。输入键会规范化为字符串；001 和 1 保持不同，数字 1 与字符串 "1" 则视为相同。

CSV 导出

exportDiffCsv(result, {
  changesOnly: true,  // 默认只导出发生变化的记录
  escapeFormulae: true, // 默认防止文本作为表格公式执行
});

核心导出的行号假定表头位于第 1 行；网站解析器额外保留原始记录位置。CSV 文件读取、Excel 格式解析和下载 UI 由网站提供，不是核心包依赖。

运行环境与边界

  • ESM 包，Node.js 18+，或支持 structuredClone 的现代浏览器。提供 TypeScript 类型声明。
  • 支持字符串、数字、布尔值、null、undefined 单元格；不接受嵌套对象作为单元格。
  • 数值比较使用 JavaScript Number。超大整数、货币精确核对应在输入端标准化为字符串并保留文本模式。
  • 核心比较为同步函数。大表格建议放入 Worker；本站的解析和比较均在 Worker 中运行。
  • 不执行 Excel 公式，不做模糊匹配，不推断被源文件丢失的编号前导零。
  • result.before / after 保留原始记录引用；调用方需要不可变快照时，请在调用前克隆输入。

接入测量

网站完成比较后会派发 sheetdelta:compare-complete 事件，detail 仅包含是否为示例数据；导出后派发 sheetdelta:export-complete。当前没有远程接收端，也没有统计真实 UV。上线时应区分真实文件与示例、成功比较与普通访问，并在明确的隐私方案下接入统计。不要采集文件内容、编号或列值。
